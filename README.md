# Generador de contraseñas

Aplicación web sencilla para crear contraseñas aleatorias, hecha con HTML, CSS y JavaScript puro (sin dependencias).

## Funciones

- Longitud configurable de 8 a 50 caracteres (16 por defecto).
- Elección de los tipos de caracteres: mayúsculas, minúsculas, números y símbolos.
- Genera una contraseña al abrir la página y la regenera al mover el control de longitud o cambiar una opción.
- Indicador de fuerza (Débil, Media, Fuerte, Muy fuerte) según la longitud y los tipos de caracteres elegidos.
- Botón para copiar la contraseña al portapapeles.

## Cómo usarlo

1. Clona o descarga el repositorio.
2. Abre `index.html` en tu navegador.

No hace falta servidor ni instalación.

## Archivos

| Archivo | Contenido |
|---|---|
| `index.html` | Estructura de la página |
| `style.css` | Estilos |
| `app.js` | Generación de la contraseña, indicador de fuerza y copiar |
